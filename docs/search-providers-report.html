① 解析问题改写，确定本地 / 网页通道
② 选路按顺序取第一个可用 Provider
③ 检索SearXNG JSON 或页面解析
④ 过滤相关性闸门丢弃诱饵结果
⑤ 合成统一 hit → 带 [n] 引用的回答
